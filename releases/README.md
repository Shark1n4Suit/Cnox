# COELANOX Releases

Pre-built binaries (Linux x86_64, Windows x86_64). No Rust required.

See **[docs/QUICKSTART](../docs/QUICKSTART.md)** for install and usage.

**Quick (Linux):**
```bash
tar -xzf coelanox-linux-x86_64.tar.gz -C /tmp/coelanox
cd /tmp/coelanox && ./install.sh
coelanox --help
```

Download from [GitHub Releases](https://github.com/coelanox-ai/coelanox/releases).
